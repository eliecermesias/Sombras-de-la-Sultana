## Criterio de referencia

Las imágenes aportadas por el usuario se usaron como referencias de arquitectura, geografía, vestuario, textura de las manillas y atmósfera. La imagen de horror se tomó únicamente como referencia de tensión; el descarnado se mantuvo sugerido y sin copiar rasgos, maquillaje o vestuario.
