# Comments - Episodio 07

## Revision editorial

- La historia cumple estructura de inicio, nudo y desenlace.
- El inicio instala Pance como lugar familiar y vallecaucano.
- El nudo transforma el rio en amenaza mediante el reflejo de Lucia.
- El desenlace paga la culpa de Mariela y deja una advertencia clara.

## Puntos fuertes

- Contraste potente entre paseo de olla y terror nocturno.
- Elementos locales reconocibles: La Voragine, Pueblito Pance, La Curva, sancocho, lulada, mango biche.
- Regla sobrenatural clara y recordable.
- Cierre con frase de advertencia que puede funcionar en video corto.

## Pendientes de revision futura

- Confirmar si se conservara el nombre Lucia como canon.
- Decidir si Mariela debe morir definitivamente o quedar como aparicion recurrente.
- Revisar duracion final de voz para pieza de 90 segundos.
