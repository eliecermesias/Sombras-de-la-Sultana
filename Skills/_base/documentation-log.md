# Skill base: registro documental de produccion

Usar esta habilidad cada vez que se genere o modifique una pieza del proyecto.

## Cuando aplica

Aplica para:

- Cuentos.
- Guiones.
- Storyboards.
- Prompts.
- Imagenes.
- Arte generado.
- Audio.
- Video.
- Copy de publicacion.
- Ediciones o ajustes de estructura.
- Nuevas habilidades del proyecto.

## Donde registrar

Registrar el trabajo en:

`Documentation/History/YYYY-MM-DD-worklog.md`

Si ya existe un archivo para la fecha, agregar una nueva seccion al final.

Si el cambio afecta una decision de estructura, estilo, flujo o herramienta, registrar tambien en:

`Documentation/Decisions/`

## Formato de entrada recomendado

```md
## [Hora opcional] Tipo de trabajo - Episodio o area

### Entrega

- ...

### Archivos creados o modificados

- `ruta/al/archivo.md`

### Habilidades usadas o actualizadas

- `Skills/...`

### Notas

- ...

### Pendientes

- ...
```

## Regla

Si una entrega no esta registrada, el trabajo queda incompleto.
