# Skill base: sistema de prompts visuales

Usar esta habilidad para crear o mejorar prompts de imagen, arte base o image-to-video.

## Prompt visual recomendado

Cada prompt debe contener:

- Sujeto principal.
- Lugar caleño o referencia arquitectonica.
- Momento del dia.
- Atmosfera.
- Luz y color.
- Composicion vertical 9:16.
- Estilo cinematografico.
- Restricciones: sin texto, sin marca de agua, sin gore si no aplica.

## Formula base

```text
[main subject] in [specific Cali location or local setting], [time of day], [emotional action], [cinematic composition], [lighting], [atmosphere], [visual texture], urban Colombian horror legend, vertical 9:16, no text, no watermark, no gore
```

## Restricciones generales

- No incluir letras legibles en periodicos, afiches, entradas o letreros a menos que sea imprescindible.
- No usar sangre explicita cuando el guion pida sugerencia.
- No mostrar rostros sobrenaturales completos si la escena depende del misterio.
- No convertir lugares caleños en castillos, catacumbas europeas o fantasia medieval.
- No usar colores neon excesivos si el episodio pide sobriedad historica.

## Prompts image-to-video

Cada indicacion de movimiento debe ser breve y fisica:

- slow push-in
- subtle handheld tension
- drifting tropical mist
- flickering sodium street light
- slow lateral tracking shot
- smoke covering the frame
- shadow stretching across the wall
- rain moving in layers

Evitar:

- fast action
- chaotic camera
- exaggerated morphing
- jump scare
- face distortion
